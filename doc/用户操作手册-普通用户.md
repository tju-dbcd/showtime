# SHOWTIME 用户操作手册（普通用户）

> 本手册面向购票用户，覆盖 SHOWTIME 票务平台的注册登录、浏览演出、选座购票、支付、订单管理、电子票、退票与改签、个人中心等操作。
> 线上环境以管理员实际发布内容为准，截图/示例仅为演示。

## 1. 注册与登录

### 1.1 注册

1. 点击首页右上角「登录」→ 在登录页点击「注册」入口，进入注册页。
2. 填写注册信息：
   - **用户名**：必填，3~50 位，字母开头；
   - **昵称**：选填；
   - **手机号**：必填；
   - **邮箱**：选填（需为有效邮箱格式）；
   - **密码**：必填，至少 8 位且包含字母和数字；
   - **确认密码**：与密码一致。
3. 点击「注 册」，注册成功后返回登录页，使用刚注册的账号登录。

> 注册接口按 IP 限流（3 次/分钟），连续触发会提示稍后重试。

### 1.2 登录

- 在登录页输入**用户名**与**密码**，点击「登录」。
- 登录成功后自动进入系统；同一账号只允许一个活跃会话，新设备登录会使旧会话失效。
- 忘记密码请联系平台管理员（当前版本未提供自助找回）。

### 1.3 退出登录

- 点击右上角用户头像进入个人中心 → 左侧「退出登录」，确认后退出。

## 2. 浏览演出

### 2.1 首页

- 顶部导航：**首页 / 演出列表 / 我的订单**；右侧显示登录状态。
- 首页展示在售演出：热门演出与近期演出海报卡片；点击卡片进入演出详情。
- 顶部搜索框输入关键词回车，跳转到演出列表并自动筛选。

### 2.2 演出列表（搜索）

- 「演出列表」页支持按关键词搜索、分类筛选、分页浏览已发布（`PUBLISHED`）的演出。
- 每张卡片展示海报、名称等信息，点击进入详情。

### 2.3 演出详情

演出详情页展示：

- 演出名称、海报、分类/标签、简介、时长等；
- 可售票的**场次列表**：每场展示开演时间与可售票区/票价信息；
- 演出关联的公告/营销内容（如有）。

选择目标场次后，点击「选座购票」进入选座页。

## 3. 选座购票

1. **进入选座页**：在演出详情选择场次后进入 `/seat-selection/:eventId`。
2. **查看座位图**：页面按分区展示座位（舞台/票区标注）。图例区分：
   - 可选座位（点击选中，再次点击取消）；
   - 已售/不可选座位；
   - 已被其他用户锁定的座位。
3. **选择座位**：点击想购买的座位（通常一次可多选，具体限购以场次配置为准）。
4. **提交订单**：点击「提交订单」，系统会先**锁定所选座位**（锁定期默认 10 分钟），随后创建订单。
   - 若座位已被他人抢先锁定/购买，会提示座位不可用，请重新选择。
   - 锁定中的座位请尽快完成支付；超时未支付订单会被自动取消并释放座位。
5. 下单成功后，跳转/返回「我的订单」进行支付。

> 下单带幂等保护（每次自动生成 `Idempotency-Key`），网络重试不会产生重复订单；如提示重复提交冲突，请刷新订单列表确认。

## 4. 支付

- 在「我的订单」中，状态为**待支付**的订单可点击「去支付」。
- 支付弹窗中选择支付方式（当前为演示环境，提供**支付宝 / 微信**模拟支付），点击确认完成支付。
- 支付成功后订单状态变为**已支付**，随后自动出票（状态变为**已出票**），可在订单详情查看电子票。
- 待支付订单也可在详情页/列表页点击「取消订单」主动取消，取消后座位释放。

> 当前为 Mock 支付，不会产生真实扣款。

## 5. 我的订单

「我的订单」页按状态分 Tab 展示本人订单：

| Tab | 说明 |
|-----|------|
| 全部 | 所有订单 |
| 待支付 | `PENDING_PAY`：可「去支付」或「取消订单」 |
| 已支付 | `PAID`：等待/正在出票 |
| 已出票 | `ISSUED`：可查看电子票、申请退票/改签 |
| 部分退款 | `PART_REFUND`：部分票已退 |
| 已退款 | `REFUNDED`：已退票完成 |
| 已取消 | `CANCELLED`：已取消 |

- 点击「查看详情」进入订单详情页，查看订单基本信息、票品明细（座位/票区/单价）、支付流水与电子票。
- 订单/退款状态变化会通过**实时通知**推送（见第 10 节），也可手动刷新列表。

## 6. 电子票查看

订单出票后，在**订单详情**的「电子票」区查看：

- 每张票显示票号、状态（`UNUSED` 未使用等）与**二维码**；
- 入场时向工作人员出示二维码进行**核销**（当前版本核销由管理员在管理后台「电子票核销」页操作）；
- 票面状态为已核销/已退票/已改签后二维码不可再使用。

## 7. 退票

> 退票仅对**已出票**订单开放，是否可退、退款金额取决于退票策略（距开演时间阶梯扣费）与管理员审核结果。

1. 在订单详情页点击「申请退票」。
2. 在弹窗中选择要退的票（支持部分退/全退，以页面可选范围为准），系统先展示**退票报价**（退款金额、服务费等）。
3. 确认后提交退票申请，进入**待审核**状态。
4. 管理员审核通过后，系统自动执行退款并更新订单状态（`REFUNDED` / `PART_REFUND`）；审核驳回则订单维持原状态。
5. 退款处理进度可通过订单详情或实时通知跟踪。

## 8. 改签

> 改签规则：**仅支持同演出更换场次**，换几张票就要选择几个目标座位（与原票 1:1 对应）；是否允许改签、是否收费取决于改签策略与管理员审核。

1. 在订单详情页点击「申请改签」。
2. 选择目标场次（页面只展示在售且与原场次不同的场次），进入选座页按原票数量 1:1 选择目标座位。
3. 返回后查看改签报价，确认提交改签申请，进入**待审核**状态。
4. 审核通过后：
   - 无需补差价：改签自动完成；
   - 需补差价：在改签申请面板点击「支付差价」，支付后改签完成，生成新场次的电子票。
5. 审核驳回时订单维持原状态，原座位/电子票不受影响。

## 9. 个人中心

点击右上角头像/用户名进入个人中心，左侧菜单：

### 9.1 个人资料

- 查看昵称、用户名、手机号、邮箱；
- 点击头像可**更换头像**（选择图片后自动上传保存）。

### 9.2 账号安全

- 查看已绑定手机与邮箱（当前版本不支持自助更换绑定）。

### 9.3 实名认证

- 未实名时展示「未实名认证」，点击「新增实名认证」填写**真实姓名 + 身份证号**保存；身份证号加密存储，仅展示脱敏号码。
- 可添加多条实名信息，将常用的一条「设为默认」；未通过审核的实名可「编辑」，任意一条可「删除」。
- 已完成实名（页面显示「已实名认证」）后可使用全部功能。

### 9.4 管理后台入口

- 若账号具备管理员角色，个人中心菜单会显示「管理后台」，点击进入 `/admin`（操作见《用户操作手册（管理员版）》）。

## 10. 常见问题

| 问题 | 说明 |
|------|------|
| 选座提示「座位已被锁定/已售」 | 座位被其他用户抢先锁定或购买，请重新选择其他座位；已选座位锁定 10 分钟后未支付会自动释放 |
| 下单后一直「待支付」 | 请在锁定期内完成支付；超时未支付订单会被自动取消并释放座位 |
| 订单/退款状态没变化 | 页面已接入实时通知（SignalR），也可手动刷新；状态一律以订单查询接口/页面显示为准 |
| 登录提示「登录已过期」 | Access Token 有效期 15 分钟，过期后请重新登录；长时间未操作会被安全策略登出 |
| 换设备登录后被踢下线 | 同一账号只允许一个活跃会话，后登录会使旧会话失效 |
| 退出/被踢后旧 Token 立即失效 | 系统每次请求都校验会话状态，无需担心旧登录态残留 |
| 支付/取消/退票等操作提示冲突 | 多为重复提交或状态已变化，请刷新页面后以最新状态为准 |
